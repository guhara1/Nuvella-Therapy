# 누벨라 (Nuvella) — 서울·경기·인천 출장 웰니스 마사지 안내

정적 사이트입니다. 깃허브에 올라간 `public/` 폴더를 클라우드플레어 페이지가 그대로 서비스합니다.

## 클라우드플레어 페이지 연결
1. Workers & Pages → **Pages** → Connect to Git → 이 저장소
2. 프레임워크 사전 설정: **없음(None)**
3. 빌드 명령: 비움
4. **빌드 출력 디렉터리: `public`**

## 무엇이 들어 있나
- 지역: 서울·경기·인천 전 구/군과 **대표 행정동** (번호가 붙은 동은 대표 하나로 묶음)
- 쪽 구성: 홈 · 코스안내 · 요금안내 · 이용후기 · 이용안내 · 소개 ·
  지역(시·도 → 구 → 행정동) · 자리(업소) · 코스
- 3단계 지역 찾기(시·도 → 구 → 동), 사이트맵 갈래별 분리, RSS, robots, IndexNow 키
- 업소 정보는 **안내를 위한 예시**이며 실제 영업장과 무관합니다.
- 지어낸 별점·후기를 싣지 않습니다. 길 주소를 적지 않고 행정동까지만 표시합니다.

## 다시 굽기
    python3 /root/nuvella/gen/shops.py      # 자리 목록
    python3 /root/nuvella/gen/build.py      # public/ 전체
